# Part B2: the `images:` fold, a kind on every artifact, generated schemas - Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every `artifacts:` entry names a `kind:` from the catalogue, the top-level `images:` section folds into
`artifacts:` as `kind: image`, each reader checks the kind it reads, the per-kind keys are checked by pydantic
models firn generates from simplon's model, and `simplon manifest migrate` takes any reachable manifest - old
`groups:` form or ci/cd form - to the current form in one run.

**Architecture:** The firn model gains per-kind keys (`ArtifactField` children of each `ArtifactKind`) and the
coordinates that read one entry by name with the keys each needs (`KindReader`). A new template writes a whole
Python module, `src/simplon/artifactschema.py` (one pydantic class per kind, subclassing the kind it refines and
refusing a key it does not declare, plus `REFINES`, `READERS`, `NEEDS` and `validate`). A hand-written
`src/simplon/artifactsection.py` is the one reading of the section: `check` at load (every entry has a known kind
and only that kind's keys, well shaped), `entry` at use (the entry is of the kind the task reads, or refines it,
and has every key the coordinate needs); the readers use its typed model instead of their own key checks. The migration grows from one splice to three passes (duplicates, shape, fold), each
parsed back and line-accounted on its own. The old spellings (`images:`, `source:`, a kindless entry,
`deploy: source: { images: }`) are refused by name in the cut, with both migration routes.

**Tech Stack:** Python 3.11+, PyYAML, pydantic 2.13, pytest; firn v0.1.0 (`ghcr.io/marcozwyssig/firn:v0.1.0`,
`.firnt` templates) only through `./simplon.sh build model` / `test model`; Hugo only through
`./simplon.sh build docs`.

**Spec:** `docs/superpowers/specs/2026-10-11-ci-cd-support-and-the-artifact-chain-design.md` - parts A.5 (the
migration), A.6 (the diagnoses in the cut), B.1-B.4 (artifacts, kinds, `kind: image`, the bill), D (the model
and the bridge), and the "Order of work" table (B2 = cut 2). The previous plan, merged, is
`docs/superpowers/plans/2026-10-12-si344-b1-generated-kinds.md`; its house style and its firn guards are this
plan's starting point.

**Decisions this plan rests on (Marco, 2026-10-12, binding):**

   maps too.
2. `kind:` is required on every entry and must be a kind in `Catalogue.kinds`; a reader naming an entry of the

   second copy is dropped, differing copies are cannot-migrate (rc 1). `test_migrate.py:383` is inverted.

**The shapes (decision A, decision B):** `text` takes a string or a number and reads it as a string - exactly
what `str(...)` in today's nuget/maven/conan readers did - and refuses a bool, an empty string, a list or a
mapping; `texts` is a list of non-empty strings, stripped and deduplicated; `table` is a mapping of scalars,
read as strings; `untyped` is kept as written. A key written with NO value is refused for every shape (it is
neither absent nor a value). A key the kind does not declare is refused by name (`_known`), with the nearest
key it does declare. Requiredness is per READER, in `NEEDS`, and `simplon.artifactsection.entry` applies it
(Task 5) - the schema itself makes every key but `kind` optional, because a `local:` image needs none of
`build:image`'s keys and `build:nuget-config` needs only `registry`.

def whole_files(files: list[str] | None = None) -> int:
    """Refuse a generated file that is missing or holds nothing but firn's id line: `build model-whole`.

    firn v0.1.0 deletes a file its templates no longer produce, with rc 0, when a selector answers nothing
    (firn#966), and a template error leaves a file holding only the id line (si#344 B1 spike). The catalogue
    keeps its protected region through both; `artifactschema.py` has none, so either leaves the kernel with
    no artifact schema and a green `gen`. This runs after `model-gen` and before `model-mode`, which would
    otherwise report the files made readable and the aggregate done.

    A missing file, an id-line-only file and an empty list are each rc 1 naming what is wrong - a guard that
    was given nothing has checked nothing.
    """
    if not files:
        print("whole-files: no files given (pin them with `with: { files: [...] }`)", file=sys.stderr)
        return 1
    rc = 0
    for name in files:
        path = ROOT / name
        if not path.is_file():
            print(f"whole-files: no such file: {name} - firn deletes a file its templates no longer produce, "
                  f"with rc 0 (firn#966)", file=sys.stderr)
            rc = 1
            continue
        content = [line for line in path.read_text(encoding="utf-8").splitlines() if line.strip()]
        if all(_ANY_ID_LINE.search(line) for line in content):
            print(f"whole-files: {name} holds nothing but firn's id line - what a template error leaves "
                  f"behind; run `./simplon.sh build model` again and read firn's error", file=sys.stderr)

def _parse(text: str) -> tuple[object, str]:
    """(the document, ''), or (None, the refusal) when it is not valid YAML - reprinted from the parser's mark,
    because it was handed a STRING and its `str()` would name "<unicode string>"."""
    try:
        return yaml.safe_load(text), ""
    except yaml.YAMLError as exc:
        mark = getattr(exc, "problem_mark", None)
        where = f"line {mark.line + 1}, column {mark.column + 1}: " if mark is not None else ""
        problem = getattr(exc, "problem", None) or str(exc)
        return None, f"it is not valid YAML, so nothing can be moved: {where}{problem}"


def _kinds_read(old: dict) -> dict[str, dict[str, str]]:
    """entry name -> {coordinate: the kind it reads}, for every command whose `task:` is a coordinate that
    reads ONE `artifacts:` entry (`READERS`, generated from the model) and whose `with:` names that entry."""
    found: dict[str, dict[str, str]] = {}

    def walk(node: object) -> None:
        if isinstance(node, dict):
            task, bound = node.get("task"), node.get("with")
            if isinstance(task, str) and task in READERS and isinstance(bound, dict) \
                    and isinstance(bound.get("name"), str):
                found.setdefault(bound["name"], {})[task] = READERS[task]
            for value in node.values():
                walk(value)
        elif isinstance(node, list):
            for value in node:
                walk(value)

    for area in ("ci", "cd", "support"):
        walk(old.get(area))
    return found


def _derived_kind(name: str, read: dict[str, dict[str, str]]) -> tuple[str, str]:
    """(the kind, '') for a kindless entry exactly one kind of reader reads, else ('', the refusal)."""
    readers = read.get(name, {})
    kinds = sorted(set(readers.values()))
    if len(kinds) == 1:
        return kinds[0], ""
    if not kinds:
        return "", (f"artifacts: {name} declares no `kind:`, and no command reads it through a catalogue "
                    f"task that names its kind ({', '.join(sorted(READERS))}) - add `kind:` to it by hand, "
                    f"one of {', '.join(REFINES)}, and run again")
    said = ", ".join(f"{coordinate} reads a {kind}" for coordinate, kind in sorted(readers.items()))
    return "", (f"artifacts: {name} declares no `kind:`, and the commands that read it disagree ({said}) - "
                "add `kind:` by hand, and run again")


#: A key line's rest, split into its value and a trailing comment (`  iol: x:1   # why`).
_VALUE = re.compile(r"^(?P<value>.*?)(?P<comment>\s+#.*)?$")


def _rewrite_entry(child: list[str], kind: str | None,
                   scalar: str | None) -> tuple[list[str], list[str], list[str]] | str:
    """One `  <name>:` block of `images:` or `artifacts:`, rewritten in place: `kind: <kind>` written as its
    first key when `kind` is given, a `source:` key renamed `path:`, and a bare image reference (`scalar`)
    written as `{ kind: image, local: "<reference>" }` with its comment kept on the line. Returns
    (the lines, the lines it removed, the lines it added), or the reason it cannot."""
    at = next(i for i, line in enumerate(child) if _CHILD.match(line))
    head = _CHILD.match(child[at])
    assert head is not None  # `at` is the first line `_CHILD` matches
    key, parts = head.group("key"), _VALUE.match(head.group("rest"))
    assert parts is not None  # a lazy value and an optional comment match every string
    value, comment = parts.group("value").strip(), parts.group("comment") or ""
    lines = list(child)
    if scalar is not None:
        lines[at] = f"  {key}: {{ kind: image, local: {json.dumps(scalar)} }}{comment}"
        return lines, [child[at]], [lines[at]]
    if value.startswith("{"):
        if not value.endswith("}"):
            return f"{key} is a flow mapping written across lines - write it on one line or in block style"
        inner = value[1:-1].strip()
        if kind:
            inner = f"kind: {kind}, {inner}" if inner else f"kind: {kind}"
        inner = re.sub(r"(^|,\s*)source(\s*:)", r"\1path\2", inner)
        lines[at] = f"  {key}: {{ {inner} }}{comment}"
        return lines, [child[at]], [lines[at]]
    if value:
        return f"{key} holds {value!r}, which is neither a mapping nor an image reference"
    body = [i for i in range(at + 1, len(child))
            if child[i].strip() and not child[i].lstrip().startswith("#")]
    if not body:
        return f"{key} holds nothing - an entry needs at least its `kind:`"
    indent = len(child[body[0]]) - len(child[body[0]].lstrip())
    removed: list[str] = []
    added: list[str] = []
    for i in body:
        if child[i].startswith(" " * indent + "source:"):
            lines[i] = " " * indent + "path:" + child[i][indent + len("source:"):]
            removed.append(child[i])
            added.append(lines[i])
    if kind:
        written = " " * indent + f"kind: {kind}"
        lines.insert(at + 1, written)
        added.append(written)
    return lines, removed, added


def _deploy_source(block: list[str]) -> tuple[list[str], list[str], list[str]] | str:
    """The `deploy:` block with `source:`'s `images` renamed `artifacts`, flow (`source: { images: x }`) or
    block (`source:` / `    images: x`)."""
    lines = list(block)
    for i, line in enumerate(block):
        match = _CHILD.match(line)
        if not match or match.group("key") != "source":
            continue
        if "{" in match.group("rest"):
            lines[i] = re.sub(r"([{,]\s*)images(\s*:)", r"\1artifacts\2", line, count=1)
            return lines, [line], [lines[i]]
        for j in range(i + 1, len(block)):
            inner = block[j]
            if inner.strip() and not inner.lstrip().startswith("#") and len(inner) - len(inner.lstrip()) <= 2:
                break
            if re.match(r"^\s{4,}images\s*:", inner):
                lines[j] = inner.replace("images", "artifacts", 1)
                return lines, [inner], [lines[j]]
    return ("deploy: source: names `images:` in a shape the fold does not rewrite - write "
            "`source: { artifacts: <name> }` by hand, and run again")


def _fold_expected(old: dict, kinds: dict[str, str]) -> dict:
    """What the folded text must parse to, built from the DATA - `_expected`'s role for the second pass."""
    out = {k: v for k, v in old.items() if k != "images"}
    folded: dict = {}
    for name, body in (old.get("artifacts") or {}).items():
        if isinstance(body, dict):
            body = dict(body)
            if "source" in body:
                body["path"] = body.pop("source")
            if name in kinds:
                body["kind"] = kinds[name]
        folded[name] = body
    for name, body in (old.get("images") or {}).items():
        folded[name] = ({"kind": "image", "local": body} if isinstance(body, str)
                        else {"kind": "image", **(body or {})})
    if "images" in old or "artifacts" in old:
        out["artifacts"] = folded or old.get("artifacts", old.get("images"))
    deploy = old.get("deploy")
    if isinstance(deploy, dict) and isinstance(deploy.get("source"), dict) and "images" in deploy["source"]:
        source = dict(deploy["source"])
        source["artifacts"] = source.pop("images")
        out["deploy"] = {**deploy, "source": source}
    return out


def _fold(text: str) -> Migration:
    """Pass 2 (si#344 B2): `images:` into `artifacts:` with `kind: image`, a `kind:` on every artifacts
    entry (derived from the coordinate that reads it), `source:` into `path:`, and `deploy: source:
    { images: x }` into `{ artifacts: x }`. `images:` beside an existing `artifacts:` is appended to it; the
    comments above `images:` stay where they stood."""
    old, reason = _parse(text)
    if reason:
        return Migration("refused", text, (), reason)
    if not isinstance(old, dict):
        return Migration("current", text)
    images, artifacts, deploy = old.get("images"), old.get("artifacts"), old.get("deploy")
    source = deploy.get("source") if isinstance(deploy, dict) else None
    entries = artifacts if isinstance(artifacts, dict) else {}
    kindless = [str(n) for n, body in entries.items() if isinstance(body, dict) and "kind" not in body]
    renamed = [str(n) for n, body in entries.items() if isinstance(body, dict) and "source" in body]
    shapeless = [str(n) for n, body in entries.items() if not isinstance(body, dict)]
    deploy_images = isinstance(source, dict) and "images" in source
    unreadable = artifacts is not None and not isinstance(artifacts, dict)
    # "current" only for a manifest this pass would leave as the loader wants it: an `artifacts:` that is
    # not a mapping, or an entry that is not one, is NOT current - it is cannot-migrate, named below.
    if ("images" not in old and not kindless and not renamed and not shapeless and not deploy_images
            and not unreadable):
        return Migration("current", text)

    def refused(why: str) -> Migration:
        return Migration("refused", text, (), why)

    if images is not None and not isinstance(images, dict):
        return refused(f"images: is a {type(images).__name__}, not a mapping of image name to entry - fix it "
                       "by hand, and run again")
    if unreadable:
        return refused(f"artifacts: is a {type(artifacts).__name__}, not a mapping of artifact name to entry "
                       "- fix it by hand, and run again")
    for name in shapeless:
        value = entries[name]
        if value is None:
            return refused(f"artifacts: {name} holds nothing - an entry names its `kind:` and its keys; write "
                           "them by hand, and run again")
        return refused(f"artifacts: {name} is {value!r}, not a mapping - an entry names its `kind:` and its "
                       f"keys; an image reference is written `{name}: {{ kind: image, local: \"{value}\" }}` - "
                       "fix it by hand, and run again")
    images = images or {}
    both = sorted(str(name) for name in set(images) & set(entries))
    if both:
        return refused(f"'{both[0]}' is both an `images:` and an `artifacts:` entry, and one section cannot "

    if extra:
        return refused(f"the folded text has a line the original did not: {extra}")

def migrate_text(text: str, *, unknown_groups_into: str | None = None) -> Migration:
    """Rewrite `text` into the current form: `_shape`, then `_fold` - see the module head. "current" only
    when no pass changed a byte; a refusal in any pass hands back the input untouched."""
    if unknown_groups_into not in (None, "ci", "cd"):
        raise ValueError(f"unknown_groups_into must be 'ci' or 'cd', not {unknown_groups_into!r}")
    current, moved = text, []
    for step in (lambda t: _shape(t, unknown_groups_into=unknown_groups_into), _fold):
        result = step(current)
        if result.status == "refused":
            return Migration("refused", text, (), result.reason)
        if result.status == "migrated":
            current, moved = result.text, [*moved, *result.moved]
    if current == text:
        return Migration("current", text)
    return Migration("migrated", current, tuple(moved))

"""A YAML loader that refuses a key written twice in one mapping (si#344 B2).

PyYAML keeps the LAST of two equal keys and drops the first without a word - which is how cleon's manifest
carried `release:` and `support:` twice, and why `simplon.tasks.migrate` keeps a line accounting at all. A
duplicate key is not valid YAML (the keys of a mapping are unique), so this raises the parser's own
`ConstructorError`: every caller that already reports a YAMLError with its line and column - the loader's
"is not valid YAML" diagnosis first among them - reports this one too, with the key and both lines, and the
refusal census gains no raise site.

A merge key (`<<: *base`) is not a duplicate: a key written beside it overrides the merged one on purpose.
"""
from __future__ import annotations

from collections.abc import Hashable
from typing import Any

import yaml
from yaml.constructor import ConstructorError, SafeConstructor
from yaml.nodes import MappingNode, ScalarNode

MERGE_TAG = "tag:yaml.org,2002:merge"


class UniqueKeyLoader(yaml.SafeLoader):
    """`yaml.SafeLoader`, refusing a scalar key one mapping writes twice."""

    def construct_mapping(self, node: MappingNode, deep: bool = False) -> dict[Hashable, Any]:
        seen: dict[Hashable, ScalarNode] = {}
        for key_node, _ in node.value:
            if not isinstance(key_node, ScalarNode) or key_node.tag == MERGE_TAG:
                continue
            # The CONSTRUCTED key, not the spelling: `yes:` and `true:` are both True, and YAML keeps only
            # the second of them exactly as it does for two `true:` (measured, review finding M4).
            key = key_of(key_node)
            if key in seen:
                first = seen[key]
                spelled = "" if first.value == key_node.value else f", as `{first.value}:`"
                raise ConstructorError(
                    "while constructing a mapping", node.start_mark,
                    f"found `{key_node.value}:` a second time (first on line {first.start_mark.line + 1}"
                    f"{spelled}); YAML would keep only this copy, so the first one is lost", key_node.start_mark)
            seen[key] = key_node
        return super().construct_mapping(node, deep=deep)


def key_of(node: ScalarNode) -> Hashable:
    """The key YAML constructs from a scalar key node - the value two keys collide on."""
    value: Hashable = SafeConstructor().construct_object(node)
    return value


def load(text: str) -> object:
    """`yaml.safe_load(text)`, refusing a duplicate key."""
    return yaml.load(text, Loader=UniqueKeyLoader)

def _duplicates(text: str) -> list[tuple[str, int, int, int]]:
    """Every scalar key one mapping writes twice, as (dotted path, the key's column, the first copy's key
    line, the second's), 0-based lines, in document order. Composed, not constructed: construction is where
    YAML would drop the first copy."""
    found: list[tuple[str, int, int, int]] = []

    def walk(node: object, path: str) -> None:
        if isinstance(node, yaml.MappingNode):
            seen: dict[Hashable, int] = {}
            for key, value in node.value:
                if isinstance(key, yaml.ScalarNode) and key.tag != MERGE_TAG:
                    where = f"{path}.{key.value}" if path else str(key.value)
                    constructed = key_of(key)  # `yes` and `true` collide, as they do for the loader
                    if constructed in seen:
                        found.append((where, key.start_mark.column, seen[constructed], key.start_mark.line))
                    else:
                        seen[constructed] = key.start_mark.line
                    walk(value, where)
                else:
                    walk(value, path)
        elif isinstance(node, yaml.SequenceNode):
            for item in node.value:
                walk(item, path)

    walk(yaml.compose(text, Loader=yaml.SafeLoader), "")
    return found


def _span(lines: list[str], at: int, indent: int) -> tuple[int, int]:
    """The half-open line range of the block whose key line is `at`: the comment and blank lines directly
    above it (`_blocks`' rule - a comment at the key's indent or less), the key line, and every line under
    it up to the next content line indented no deeper than the key. Trailing comments and blank lines
    belong to whatever comes next, as they do in `_blocks`. Read by indentation: a block value's end mark
    sits on the NEXT key's line (measured on cleon), so it cannot say where this one ends."""
    def is_comment_or_blank(line: str) -> bool:
        return not line.strip() or line.lstrip().startswith("#")

    end = at + 1
    while end < len(lines) and (is_comment_or_blank(lines[end])
                                or len(lines[end]) - len(lines[end].lstrip()) > indent):
        end += 1
    while end > at + 1 and is_comment_or_blank(lines[end - 1]):
        end -= 1
    top = at
    while top > 0 and (not lines[top - 1].strip()
                       or (lines[top - 1].lstrip().startswith("#")
                           and len(lines[top - 1]) - len(lines[top - 1].lstrip()) <= indent)):
        top -= 1
    return top, end


def _dedupe(text: str) -> Migration:
    """Pass 0 (si#344 B2): a key written twice in one mapping. YAML keeps the second copy and loses the
    first, so the loader refuses it; here an IDENTICAL second copy - the same lines, comments included - is
    dropped, and copies that differ are refused, because only a person can say which one was meant."""
    def refused(why: str) -> Migration:
        return Migration("refused", text, (), why)

    try:
        _duplicates(text)
    except yaml.YAMLError:
        return refused(_parse(text)[1])
    lines = text.splitlines()
    removed: list[str] = []
    moved: list[str] = []
    while True:
        found = _duplicates("\n".join(lines) + "\n")
        if not found:
            break
        path, indent, first, second = found[-1]  # the last first: dropping it moves no line above it
        if first == second or lines[first][:indent].strip() or lines[second][:indent].strip():
            return refused(f"{path} is written twice where the splice cannot cut a copy out - inside a flow "
                           f"mapping or a sequence item (line {second + 1}) - merge the two by hand, and run again")
        a0, a1 = _span(lines, first, indent)
        b0, b1 = _span(lines, second, indent)
        if [line.strip() for line in lines[a0:a1] if line.strip()] != \
                [line.strip() for line in lines[b0:b1] if line.strip()]:
            return refused(f"{path} is written twice, on lines {first + 1} and {second + 1}, and the two copies "
                           "differ - YAML keeps only the second, so merge them into one by hand, and run again")
        removed += lines[b0:b1]
        del lines[b0:b1]
        moved.insert(0, f"{path}: written twice, identically (lines {first + 1} and {second + 1}) - the "
                        "second copy dropped")
    if not moved:
        return Migration("current", text)
    new = "\n".join(lines) + ("\n" if text.endswith("\n") else "")
    parsed, reason = _parse(new)
    if reason:
        return refused(f"the text without its second copies does not parse back: {reason}")
    if parsed != yaml.safe_load(text):
        return refused("the text without its second copies does not parse back to the same manifest")
    lost, extra = _accounting(text.splitlines(), new.splitlines(), removed, [])
    if lost or extra:
        return refused(f"dropping a second copy changed a line it should not have: {lost or extra}")
    return Migration("migrated", new, tuple(moved))
```

    refines it"), validated into its generated model, with every key `coordinate` needs.

A PRODUCT asks one question of it: `is_a(kind, wanted)` - "is this entry an image?" - so that its own code
never restates which kinds refine which (`kind == "image"` would miss every kind that refines `image`).

THE ONE IMPORTER OF THE GENERATED MODULE on the loader's path, and that is a guard, not a style. firn
deletes `artifactschema.py` or leaves only its id line with rc 0 (firn#966). The loader imports this module,
so a broken schema would otherwise stop every `./simplon.sh` command - `build model`, which would regenerate
it, included - with a traceback. Here it stops them with the way out.

THE CENSUS SEES ALL OF IT. Each refusal here is a `raise ValueError` the refusal census reaches from the
loader (`check`) and from `tasks.image.declared` (`entry`); a shape or unknown-key refusal is raised in the
generated root's validators, which the walk reaches through the model classes. `_validated` re-raises what a
model raised and carries `_validation_message`, the census's funnel: it refuses nothing of its own. The readers
that read the section INLINE (`tasks.artifact`, `.conan`, `.nuget`, `.maven`) still fetch it themselves and
hand `entry` the SECTION, never the document, so they stay in the census's `READS_INLINE` and the hole
`tasks/maven.py`'s `_declared` describes stays closed.

from __future__ import annotations

from collections.abc import Mapping
from typing import TypeVar

from pydantic import ValidationError

try:
    from simplon import artifactschema
    REFINES = artifactschema.REFINES
    READERS = artifactschema.READERS
    NEEDS = artifactschema.NEEDS
    _ROOT = artifactschema.ArtifactEntry
except Exception as exc:  # ImportError, SyntaxError, AttributeError: each is what firn#966 can leave behind
    raise ImportError(
        "simplon.artifactschema is missing, empty or broken - firn deletes or half-writes it with rc 0 "
        "(firn#966), and nothing that loads a manifest runs without it. In simplon's checkout: "
        "`git checkout -- src/simplon/artifactschema.py`, then `./simplon.sh build model` and read firn's "
        "own error; in an installed kernel, reinstall it") from exc

SECTION = "artifacts"

Entry = TypeVar("Entry", bound="artifactschema.ArtifactEntry")


def accepts(parents: Mapping[str, str], wanted: str, kind: str) -> bool:
    """Whether a reader of `wanted` accepts an entry of `kind`: `kind` IS `wanted`, or refines it at any
    distance. `parents` maps each kind to the one it refines, "" for the root (`Catalogue.kinds`, `REFINES`).
    A kind `parents` does not declare is accepted by nothing, and a circle - which `catalogue.loads` refuses -
    ends the walk rather than looping."""
    seen: set[str] = set()
    at = kind
    while at in parents and at not in seen:
        if at == wanted:
            return True
        seen.add(at)
        at = parents[at]
    return False


def is_a(kind: str, wanted: str) -> bool:
    """Whether an entry of `kind` is a `wanted` - the kind itself or one that refines it. The question a
    product's own code asks (`is_a(body["kind"], "image")`), answered from the kernel's vocabulary."""
    return accepts(REFINES, wanted, kind)


def _validation_message(error: ValidationError) -> str:
    """The first refusal's own sentence - the generated validators', verbatim - or `'<key>': <pydantic's
    message>` for a case they did not rule on (none is left, which `test_generated_schema.py` holds)."""
    details = error.errors(include_url=False)
    for detail in details:
        original = (detail.get("ctx") or {}).get("error")
        if isinstance(original, Exception):
            return str(original)
    detail = details[0]
    location = ".".join(str(part) for part in detail.get("loc", ()))
    return f"'{location}': {detail.get('msg', 'invalid')}"


def _validated(kind: str, body: Mapping[str, object], where: str) -> artifactschema.ArtifactEntry:
    try:
        return artifactschema.validate(kind, body)
    except ValidationError as error:
        raise ValueError(f"{where}: {_validation_message(error)}") from None


def check(document: Mapping[str, object], kinds: Mapping[str, str], source: str) -> None:
    """Every entry of `document`'s `artifacts:` is a mapping, names one of `kinds`, and declares only its
    kind's keys, in their shapes - or a ValueError naming the entry. `kinds` is the catalogue's, the authority
    at load; a load without a catalogue passes `REFINES`, the same model's output, so no load skips the
    check. What a READER needs is not asked here: an entry no placed command reads needs nothing."""
    raw = document.get(SECTION)
    if raw is None:
        return
    if not isinstance(raw, Mapping):
        raise ValueError(f"{source}: `{SECTION}:` must be a mapping of artifact name to its entry, "
                         f"found {type(raw).__name__}")
    for name, body in raw.items():
        where = f"{source}: '{SECTION}.{name}'"
        if not isinstance(body, Mapping):
            raise ValueError(f"{where} is not a mapping - an artifact declares its `kind:` and its keys")
        kind = body.get("kind")
        if not isinstance(kind, str) or kind not in kinds:
            raise ValueError(f"{where} declares `kind: {kind}`, which the catalogue does not declare; the "
                             f"kinds are: {', '.join(kinds)}")
        _validated(kind, body, where)


def entry(section: Mapping[str, object], name: str, wanted: type[Entry], source: str, coordinate: str) -> Entry:
    """The entry `name`, validated as the generated model of its kind - `wanted`'s kind or one that refines
    it - and holding every key `coordinate` needs (`NEEDS`, in the model). A ValueError says which kind it is
    and which the task reads, or which key is missing and every key the coordinate reads."""
    if READERS.get(coordinate) != wanted.KIND:
        # Not a refusal of the manifest: a body named a coordinate the model does not route to its kind.
        raise KeyError(f"{coordinate} is not a reader of '{wanted.KIND}' in the model (READERS)")
    body = section[name]
    where = f"{source}: '{SECTION}.{name}'"
    if not isinstance(body, Mapping):
        raise ValueError(f"{where} is not a mapping - an artifact declares its `kind:` and its keys")
    kind = body.get("kind")
    if not isinstance(kind, str) or kind not in REFINES:
        raise ValueError(f"{where} names no kind this kernel knows ({kind!r}); the kinds are: "
                         f"{', '.join(REFINES)}")
    if not accepts(REFINES, wanted.KIND, kind):
        raise ValueError(f"{where} is of kind '{kind}', and this task reads a '{wanted.KIND}' or a kind that "
                         f"refines it - name an entry of that kind, or change the entry's `kind:`")
    validated = _validated(kind, body, where)
    if not isinstance(validated, wanted):
        # Not a refusal either: the generated classes and REFINES disagree, which
        # test_a_kind_that_refines_another_is_its_subclass holds at zero.
        raise TypeError(f"artifactschema.{type(validated).__name__} does not subclass {wanted.__name__} although "
                        f"REFINES says '{kind}' refines '{wanted.KIND}' - run `./simplon.sh build model`")
    needs = NEEDS[coordinate]
    for key in needs:
        if getattr(validated, key) is None:
            raise ValueError(f"{where} declares no `{key}:`, which {coordinate} needs - it reads "
                             f"{', '.join(needs)}")
    return validated
```

                   coordinate: str = "build:image") -> Image:

```python
    def artifacts(self, document: Mapping[str, object]) -> list[str]:
        # Each entry with the kind it DECLARES (si#344 B2) - `load` has held every kind to the catalogue
        # before the bridge runs, so the kind is a resource of simplon.vocabulary - and its `path:` when it has
        # one. `registry:` stays out: the model's Registry is a resource of its own, and no reader needs one yet.
        lines: list[str] = []
        entries = document.get("artifacts")
        if entries is None:
            return lines
        if not isinstance(entries, Mapping):
            raise ModelExportError(f"artifacts: is a {type(entries).__name__}, not a mapping")
        for entry, body in entries.items():
            kind = body.get("kind") if isinstance(body, Mapping) else None
            if not isinstance(kind, str):
                raise ModelExportError(f"artifacts: {entry} declares no kind the model can name")
            fields = [f"key = {_q(str(entry))}", f"kind = simplon.vocabulary.{mangle(kind)}"]
            path = body.get("path")
            if isinstance(path, str):
                fields.append(f"path = {_q(path)}")
            lines += _block(f"artifacts {self.names(str(entry), 'a_')} typeOf simplon.pipeline.Artifact",
                            fields)
        return lines
```
