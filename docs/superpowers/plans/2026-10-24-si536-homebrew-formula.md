# si#536 Homebrew formula: build, test, release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Three kernel tasks turn a product's wheel into a Homebrew formula:
- `build:homebrew-formula` renders it, with no template;
- `test:homebrew-formula` audits it and records a verdict;
- `release:homebrew-tap` commits it to a tap and reports one of three outcomes.

**Architecture:**
- `adapters/pypi.py` reads PyPI's JSON API.
- `tasks/homebrewformula.py` holds the pure parts: wheel metadata, class name and render.
- `tasks/homebrewclosure.py` measures the install closure inside the pinned brew image.
- `tasks/homebrewtap.py` holds the test body and the release body. The release body commits through `adapters.repofile` (si#535) with the token si#534 derives.
- The kind and the three catalogue tasks are modelled in firn and generated by `build model`.

**Tech Stack:** Python 3.12; `zipfile` and `email` for the wheel metadata; `urllib` for PyPI; docker with `ghcr.io/homebrew/brew:7.0.9`; pytest with real local HTTP servers.

**Spec:** `docs/superpowers/specs/2026-10-18-si449-homebrew-tap-design.md`, section D and both amendments of 2026-10-24. The prototype that produced the merged homebrew-tap#1 is on si#449 comment 6386665119. Its render was green under `brew audit --strict --online --new`.

**Depends on:** si#534 (`token: app`, `repository` binding) and si#535 (`adapters.repofile`), both merged.

## Global Constraints

- **Image:**
  - `ghcr.io/homebrew/brew:7.0.9@sha256:00b643d72ab0ee27c64e3e552d08c66e1bb5272bdf4ed28964e27aa5764f2503`;
  - held in one module constant, validated with `docker.pinned_image(...)` at import time, as `tasks/allure.py:47` does.
  - No step calls `brew` on the host.
- **Kind:** `homebrew-formula` refines `file`.
- **`build:homebrew-formula` params (its `with:` keys), every one without a silent default:**
  - `shape`: only `python`. `binary` is refused with "built with firn's part F (si#449)". Anything else is refused, naming both values.
  - `source`: `pypi` or `local`. Empty or anything else is refused.
  - `depends_on`: a list of formula names, written sorted.
  - `python`: the formula name, e.g. `python@3.14`. The venv command is `python3.<minor>`, derived from it.
  - `env`: a mapping, written as `ENV["K"] = "V"` lines sorted by key.
  - `test`: `{args: [..], expect: "<text>"}`.
- **The input** is a `directory` artifact (`param: "wheel"`, `needs: path`) that holds exactly one `*.whl`. Zero or two or more wheels are refused, naming what was found.
- **From the wheel's metadata:**
  - `Name`, `Version`, `Summary`;
  - `Project-URL` whose label is `Homepage` (case-insensitive);
  - `License-Expression`;
  - the console command, which is the first `name =` in `[console_scripts]` of `entry_points.txt`.
  - A missing field is refused, naming the field.
- **The rendered shape** is the prototype's, line for line. The only changes are `env` and `test`, which come from `with:`:
  - the `url ..., using: :nounzip`;
  - `virtualenv_create(libexec, "<python3.N>")`;
  - `venv.pip_install resources`;
  - `venv.pip_install_and_link buildpath/"<wheel name with the version as #{version}>"`.
- **`source: pypi`:**
  - URL and sha256 come from `https://pypi.org/pypi/<name>/<version>/json`, from the `urls` entry whose `filename` is the wheel's;
  - its `digests.sha256` must equal the local wheel's;
  - a version or file PyPI does not list is a refusal, never a fallback.
- **`source: local`:**
  - the sha256 is the local wheel's;
  - the URL is `https://pypi.invalid/dry-run/<wheel file name>`;
  - the body logs that the PyPI comparison and the online audit run only on a real run.
- **Resources:** every distribution the closure adds, except the product and pip, gets the url and sha256 of its PyPI **sdist**. Rules:
  - a distribution with no sdist is refused, naming it;
  - a distribution in the closure (the product included) whose `Requires-Dist` carries a marker on `sys_platform`, `platform_system` or `os_name` is refused, naming it and the requirement;
  - a distribution pip installed into the venv although a `depends_on` formula provides it is refused, naming both versions.
- **`test:homebrew-formula`:**
  - takes `online` with no default;
  - runs `brew audit --strict` (plus `--online --new` when online) and `brew style` on the formula in a throwaway local tap;
  - checks the formula's `sha256` against the local wheel, and when online against PyPI too;
  - checks every resource's sha256 against PyPI;
  - writes a verdict record `{"formula": <name>, "verdict": 0|1, "runs": [{"reference": <formula path>, "id": "sha256:<formula file digest>", ...}]}`, read by `results.tested()`.
- **`release:homebrew-tap`:**
  - `publishes: true`, `token: app`, and params `repository` and `branch` (default `"main"`);
  - commits `Formula/<name>.rb`;
  - refuses an empty `GH_APP_TOKEN` by name;
  - refuses when the formula's digest is not the `id` a `tested()` subject names;
  - reports `written <sha>`, `already current` or `refused: <reason>`. Only `refused` returns 1.
- **Time limits:** `CLOSURE_TIMEOUT_S = 1800` and `AUDIT_TIMEOUT_S = 900`. A timeout is a refusal that names the limit.
- Suite: `deploy/orchestrator/.venv/bin/python -m pytest`. Docker tests skip on `conftest.docker_is_usable()` being false, like the e2e suites.

## Review Focus

- **The closure run fails transiently.** Measured: this host's ghcr bottle downloads 404 intermittently. Expected: `brew install` is retried up to 5 times inside the container, then refused with the last log lines. Never an empty closure that renders a formula without resources. Pinned in Task 3: an empty closure from a successful run is distinguished from a failed run.
- **A wheel with no `License-Expression`, only the legacy `License:`.** Expected: a refusal naming `License-Expression`, not a formula with `license ""`. Pinned in Task 2.
- **A distribution name with upper case or `_`, e.g. `PyYAML`, `typing_extensions`.** The resource name is the PyPI name lower-cased, as the prototype measured green. The PyPI lookup uses the name as pip reported it. Pinned in Task 2.
- **`source: pypi` before the upload has propagated.** PyPI answers 404 for a minute after upload. Expected: a refusal that says the version is not listed yet and that rerunning the job is safe. No retry loop that hides it. Pinned in Task 1.
- **A summary with a `"` or a `#{`.** Ruby would read it as code. Expected: `desc` escapes `\`, `"` and `#{`. Pinned in Task 2.
