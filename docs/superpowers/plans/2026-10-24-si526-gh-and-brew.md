# si#526 gh and brew host toolchains Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** With `gh` or `brew` in `toolchains:`, `support install` makes sure the tool is present, or says exactly why it could not, in one of six distinct outcomes.

**Architecture:**
- One shared adapter, `adapters/hostinstall.py`, holds the outcome type, the privileged-command wrapper and the bounded, uncaptured runner.
- Two gate adapters build on it: `adapters/brew.py` and `adapters/gh.py`, one per tool.
- `tasks/hosttools.py` reads `toolchains:` once and drives the gates in the order brew, oras, gh, claude.

**Tech Stack:** Python 3.12, pytest, and fake executables on PATH for the unit tests. A `debian:trixie` container is used for the real-instance measurement.

**Spec:** `docs/superpowers/specs/2026-10-24-si526-gh-and-brew-design.md`

## Global Constraints

- Outcomes `OFF, PRESENT, INSTALLED, SKIPPED, NO_ROUTE, FAILED`. The return code is 1 only for NO_ROUTE and FAILED. OFF prints nothing.
- Each install command has a time limit of 600 s (`INSTALL_TIMEOUT_S = 600`). A timeout is FAILED.
- **The gh keyring:**
  - URL `https://cli.github.com/packages/githubcli-archive-keyring.gpg`;
  - sha256 `6084d5d7bd8e288441e0e94fc6275570895da18e6751f70f057485dc2d1a811b`;
  - written to `/etc/apt/keyrings/githubcli-archive-keyring.gpg` with mode 0644;
  - the list file is `/etc/apt/sources.list.d/github-cli.list`, with the line
    `deb [arch=<dpkg --print-architecture> signed-by=/etc/apt/keyrings/githubcli-archive-keyring.gpg] https://cli.github.com/packages stable main`.
- **The winget command:** `winget install --id GitHub.cli -e --source winget --accept-package-agreements --accept-source-agreements`.
- **Manual-install links:** for gh, `https://github.com/cli/cli#installation`; for Homebrew, `https://brew.sh`.
- **Homebrew install.sh pin:**
  - commit `8ab1549dfa1189fd4d818a2116592d8f0ee06d8c` (2026-10-07);
  - sha256 `5f333bbe53bc490e51e7ccb1df8779b3dd6ee73a1a7379efda216edb08ccb148`;
  - URL `https://raw.githubusercontent.com/Homebrew/install/<commit>/install.sh`.
- **Homebrew prefixes:** `/opt/homebrew` on macOS (arm64 only), `/home/linuxbrew/.linuxbrew` on Linux.
- **The shellenv line printed:** `eval "$(<prefix>/bin/brew shellenv)"`. No dotfile is written.
- No em dash (U+2014) in any file written.
- Every new load-time refusal is classified in `test_refusal_census.py`. None is expected: `brew` only joins `HOST_TOOLCHAINS`.

## Review Focus

1. **A wrong keyring:** a keyring whose sha256 does not match must write nothing under `/etc/apt`. Test `test_apt_route_writes_nothing_on_a_keyring_mismatch` (Task 3).
2. **A broken binary:** a tool on PATH whose `--version` fails is not PRESENT. Without a route it is NO_ROUTE, with a route the gate installs it. Test `test_a_gh_on_path_that_does_not_run_is_not_present` (Task 3).
3. **Homebrew off PATH:** brew installed at the prefix but not on PATH is PRESENT, the gate prepends the prefix's `bin` to PATH, and the shellenv line is printed. Test `test_brew_at_the_prefix_but_off_path_is_present_and_put_on_path` (Task 2).
4. **brew before gh:** when brew is declared and freshly installed, the gh gate installs through brew in the same run. Test `test_install_runs_brew_before_gh_so_gh_can_use_it` (Task 4).
5. **gh declared, no route:** a declared gh with no route must turn `support install` red, while a SKIPPED brew on Windows must not. Tests `test_no_route_for_gh_fails_the_command` and `test_skipped_brew_does_not_fail_the_command` (Task 4).

### Task 1: The shared host-install adapter

**Files:**
- Create: `src/simplon/adapters/hostinstall.py`
- Test: `src/tests/test_hostinstall.py`

**Interfaces:**
- Produces:
  - `class State(Enum)`: OFF, PRESENT, INSTALLED, SKIPPED, NO_ROUTE, FAILED.
  - `@dataclass(frozen=True) class Outcome: state: State; detail: str = ""`.
  - `INSTALL_TIMEOUT_S = 600`.
  - `rc(outcome) -> int`: 1 for NO_ROUTE and FAILED, else 0.
  - `report(name: str, outcome: Outcome) -> None`: nothing for OFF. Otherwise `log.ok` for PRESENT and INSTALLED, `log.info` for SKIPPED, `log.error` for NO_ROUTE and FAILED. Each message starts with the name and a distinct wording: "is present", "installed", "skipped:", "no way to install it here:", "install failed:".
  - `machine_skip_reason(env: Mapping[str,str], container: bool) -> str`: the container route, or `CI`/`GITHUB_ACTIONS`=true, the same wording as `claudeplugins._skip_reason` without its `claude` check. That module is switched to call this.
  - `runs(tool: str, env) -> bool`: `[tool, "--version"]` exits 0 within 30 s.
  - `privileged(argv: list[str], *, euid: int | None = None, have=shutil.which) -> list[str] | None`: argv as-is when root, `["sudo", *argv]` when sudo is on PATH, else None. On Windows (no `os.geteuid`) it returns argv as-is.
  - `act(argv: list[str], timeout_s: float = INSTALL_TIMEOUT_S, env: Mapping[str, str] | None = None) -> str`: runs uncaptured (`run(argv, capture=False, timeout=...)`). Returns "" on rc 0, else `"<argv0> exited <rc>"`, or `"<argv0> timed out after <n> s"`.

### Task 2: The brew gate

**Files:**
- Create: `src/simplon/adapters/brew.py`
- Test: `src/tests/test_brew_gate.py`

**Interfaces:**
- Consumes: everything Task 1 produces.
- Produces:
  - `INSTALL_COMMIT`, `INSTALL_SHA256` and `INSTALL_URL`, the values from Global Constraints.
  - `prefix(system: str, machine: str) -> str | None`: `/opt/homebrew` for darwin/arm64, `/home/linuxbrew/.linuxbrew` for Linux, None otherwise.
  - `shellenv_line(prefix: str) -> str`.
  - `unsupported(system, machine) -> str`: "" when supported. Otherwise "Homebrew does not run on Windows" or "Homebrew on macOS runs only on Apple Silicon".
  - `ensure(*, env=None, container=False, system=None, machine=None, euid=None, interactive=None) -> Outcome`. Everything defaults to the real host. The parameters exist for tests.

**Order inside `ensure`:**
1. `machine_skip_reason` gives SKIPPED.
2. `unsupported` gives SKIPPED.
3. `brew` on PATH and runnable gives PRESENT.
4. `<prefix>/bin/brew` runnable gives PRESENT: prepend `<prefix>/bin` with `tools.prepend_to_path`, then `log.info` the shellenv line.
5. Root outside a container gives NO_ROUTE, with "Homebrew refuses to install as root; run support install as your own user".
6. **Install:**
   - Download the script with `fetch.download` to a temp file.
   - A sha256 mismatch is FAILED, with the expected and the got values.
   - Run `act(["/bin/bash", script], env=...)`, adding `NONINTERACTIVE=1` when `interactive` is false. `interactive` defaults to `sys.stdin.isatty()`.
   - Then step 4's check: INSTALLED, or FAILED with "install.sh finished but <prefix>/bin/brew does not run".

  - `test_brew_on_path_is_present`;
  - `test_brew_at_the_prefix_but_off_path_is_present_and_put_on_path`: monkeypatch `prefix` to tmp_path with a fake `bin/brew`; assert PATH starts with it and the output contains `shellenv`;

### Task 3: The gh gate

**Files:**
- Create: `src/simplon/adapters/gh.py`
- Test: `src/tests/test_gh_gate.py`

**Interfaces:**
- Consumes: Task 1.
- Produces:
  - `KEYRING_URL`, `KEYRING_SHA256`, `KEYRING_PATH`, `LIST_PATH` and `WINGET_ARGV`, the values from Global Constraints.
  - `route(system: str, have: Callable[[str], bool]) -> str`: one of "brew", "winget", "apt" or "". The order is brew if `have("brew")`, then winget on Windows if `have("winget")`, then apt if `have("apt-get") and have("dpkg")`.
  - `ensure(*, env=None, container=False, system=None, euid=None) -> Outcome`.

**Order inside `ensure`:**
1. `machine_skip_reason` gives SKIPPED.
2. `runs("gh")` gives PRESENT.
3. Take the route:
   - `""` gives NO_ROUTE with the manual link.
   - **brew:** `act(["brew","install","gh"])`.
   - **winget:** `act(WINGET_ARGV)`. If gh then does not run, it is INSTALLED with "open a new shell so PATH picks gh up". This is the spec's unmeasured case.
   - **apt:** `_apt_install(euid)`, below.
4. Then `runs("gh")`: INSTALLED, or FAILED with "the install finished but gh does not run".

**`_apt_install(euid) -> str`** returns "" or the reason:
1. Download the keyring to a temp file. A sha256 mismatch returns the reason and writes nothing.
2. `privileged` returns None: the gate turns this into NO_ROUTE with "needs root or sudo". Signal it with a distinct sentinel or exception, the implementer's choice, stated in the docstring.
3. With `privileged(...)`:
   - `install -D -m 0644 <tmp> KEYRING_PATH`;
   - `dpkg --print-architecture`, read captured, unprivileged;
   - write the list line to a temp file and run `install -D -m 0644 <tmp> LIST_PATH`;
   - `apt-get update`;
   - `apt-get install -y gh`.
   The first failing command stops the sequence and is the reason.

  - `test_a_gh_on_path_that_does_not_run_is_not_present`: fake gh exits 1, no route, so NO_ROUTE;
  - `test_no_route_names_the_manual_link`;

  - `test_apt_without_root_or_sudo_has_no_route`;

  - `test_a_hanging_install_is_failed_not_waited_on`: `INSTALL_TIMEOUT_S` monkeypatched to 0.2, fake brew sleeps.
